## Warnings and open points

- Duplicate row labels are tolerated, not fatal: `effecticon` (label `63` repeats) and `iprp_resistcost` (label `0` repeats). Rows remain addressable by index; label lookup returns the first match.
- V2.b zero-length strings are reported as empty cells, while ASCII `****` and missing trailing ASCII cells are reported as null cells. KotOR's accessors treat both as missing, so the parser preserves the structural difference rather than collapsing it.
- ASCII `2DA V2.0` support is validated with synthetic fixtures only: the shipped BIF contains V2.b exclusively. Quoted cells, optional `Default:` line, CRLF, `****`, quoted-empty, and short-row null fill are covered by tests.
- Encoding is CP1252 with Latin-1 fallback; all shipped column names, row labels, and cell bytes are ASCII, so encoding variance remains open for modded data.
- No shipped table exercises a u16 offset overflow or a >64 KiB string table; those are covered by synthetic failure tests.
